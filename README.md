# Cacique Kaahele Web Site

Vamos a crear un sitio web 100% responsive de una agencia de turismo

Actúa como un equipo conformado por un UX/UI Designer Senior, Director de Arte, Diseñador de Marca, Copywriter especializado en turismo, Experto en SEO y Desarrollador Frontend.

Diseña y desarrolla un sitio web completo para una agencia de turismo llamada **Cacique Kaahele**.

## Concepto de la marca

La marca representa aventura, naturaleza, cultura, playa, experiencias inolvidables y la emoción de descubrir nuevos destinos.

La web debe hacer que el usuario piense:

> "Necesito viajar."

No debe sentirse como una agencia tradicional, sino como una marca moderna que vende experiencias.

La experiencia debe transmitir:

* Alegría

* Libertad

* Descubrimiento

* Exclusividad

* Confianza

* Diversión

* Relajación

* Emoción
